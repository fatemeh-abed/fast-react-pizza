# Fast React Pizza

A pizza ordering application built with React, allowing users to browse the menu, add pizzas to their cart, customize their order, and track their orders.

## Features

- **Browse the Menu:** View available pizzas, descriptions, and prices.
- **Shopping Cart:** Add pizzas, change quantities, and remove items.
- **Order Placement:** Enter customer information and place an order.
- **Order Tracking:** View order details and track order status.
- **Priority Orders:** Mark an order as a priority when available.
- **Geolocation:** Use the customer's location to help fill in their address.
- **Responsive Interface:** Use the application across different screen sizes.

## Tech Stack

- **React** — Building the user interface with reusable components.
- **React Router** — Client-side routing and navigation.
- **Redux Toolkit** — Managing the shopping cart and application state.
- **React Redux** — Connecting React components to the Redux store.
- **Vite** — Development server and build tool.
- **CSS** — Styling the application.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/fatemeh-abed/fast-react-pizza.git
   ```

2. Navigate to the project directory:

   ```bash
   cd fast-react-pizza
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
